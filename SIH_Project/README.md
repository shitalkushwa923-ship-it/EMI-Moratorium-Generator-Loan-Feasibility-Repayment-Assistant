# EMI & Moratorium Generator

## Loan Feasibility & Repayment Assistant

A web-based loan assistance project that helps users understand loan feasibility, EMI calculations, repayment schedules, and moratorium periods.

## Features

* EMI calculation
* Loan amount and interest calculation
* Repayment assistance
* Moratorium period handling
* Loan feasibility information
* Simple and user-friendly interface

## Technologies Used

* Python
* Django
* HTML
* CSS
* JavaScript

## Project Objective

The main objective of this project is to provide a simple tool for understanding loan repayment and calculating EMI while considering applicable moratorium periods.

## How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install the required dependencies.

```bash
pip install -r requirements.txt
```

4. Run database migrations:

```bash
python manage.py migrate
```

5. Start the Django development server:

```bash
python manage.py runserver
```

6. Open the local server in your browser.
